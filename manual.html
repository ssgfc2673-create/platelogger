1. 앱 소개

차량 번호판을 찍으면 번호를 읽어 입차·출차 시각을 기록하고, 하루 단위로 방문 차량·입출차 횟수·머문 시간·반출량을 정리해 엑셀·HTML로 보냅니다.

  • 인식은 폰 안에서 합니다 — 인터넷이 필요 없고, 사진이 밖으로 나가지 않습니다(권한은 카메라 하나).
  • 덤프트럭의 흙 묻은 판, 노란 영업용 판, 지역명 두 줄 판, 주황 건설기계 판도 읽도록 맞춰져 있습니다.
  • 같은 차가 반복해서 오는 현장이면 현장 차량 목록으로 뒤 4자리만 읽혀도 번호를 맞춰 줍니다.

2. 촬영 화면 (앱을 열면 첫 화면)

부분하는 일
카메라 화면 + 가운데 십자선노란 십자선과 빨간 점이 보입니다. 빨간 점이 번호판 네모 안에 들어가게 찍으면 번호판을 훨씬 잘 찾습니다(v1.39). 십자선은 사진에 찍히지 않습니다.
두 손가락 벌리기확대(줌). 멀리 있는 번호판을 크게. 두 번 톡 = 원래 크기.
입차 출차지금 모드. 색이 켜진 쪽이 선택된 것입니다(4장 참고).
● 촬영찍고 바로 번호를 읽습니다. 「1단계 번호판 찾는 중 → 2단계 번호 읽는 중…」 뒤 확인 창이 뜹니다.
사진첩이미 찍어 둔 사진으로 기록합니다(시각은 기록하는 지금 시각).
오늘 기록하루 기록 화면으로(5장).

3. 번호 확인 창

읽은 번호가 입력칸에 들어가 있고, 아래에 찾은 번호판 후보 그림들이 나옵니다.

  • 후보 그림을 누르면 그 그림에서 읽은 번호가 입력칸에 들어갑니다(파란 테두리 = 선택).
  • 「현장 차량 목록에서 맞춤: …」이 보이면 목록에 있는 차와 뒤 4자리가 맞아 자동으로 채운 것입니다.
  • 틀렸으면 입력칸을 직접 고칩니다.
버튼뜻
확인저장번호가 맞습니다 → 기록.
임시저장바빠서 지금 확인할 시간이 없을 때. 일단 기록하고 나중에 사진을 보며 고칩니다(7장). 번호를 못 읽어 칸이 비어 있어도 «미인식»으로 기록됩니다. 인식 실패 자료도 자동으로 검증자료에 남습니다.
실패데이터저장기록과 별도로, 이 사진을 «인식 실패 자료»로 남깁니다(개발 개선용). 번호를 맞게 고친 뒤 누르면 정답도 같이 남습니다. 창은 닫히지 않습니다.
취소(기록 안 함)기록하지 않고 닫습니다.

4. 입차·출차 판정

모드찍은 번호가…결과
입차 (기본)오늘 처음 / 이미 나간 차새 입차
오늘 들어와 아직 안 나간 차「오늘 입차한 차량입니다」 창 → 출차로 처리 · 다시 입차 · 취소
출차안 나간 입차 기록이 있음그 기록의 출차
입차 기록 없음출차만 기록(입차 사진을 놓친 경우) — 합계에서는 출차 건수에 들어갑니다
같은 번호를 10초 안에 다시 찍으면 중복으로 보고 건너뜁니다(연속 촬영 방지).

5. 하루 기록 화면

  • 위 ◀ ▶ 로 날짜를 옮깁니다. 위 메뉴: 설정 · 검증자료관리.
  • 목록 표시: ⏳임시 = 임시저장한 기록 · ⚠ = 번호 형식이 아님(확인 필요) · 📷 = 촬영 사진 있음.
  • ⏳ 임시저장만 보기 (n건) — 확인이 필요한 것만 모아 봅니다(다시 누르면 전체).
  • ↺ 삭제한 기록 복구 (n건) — 지운 기록이 있을 때만 보입니다. 삭제는 표시만 하므로 언제든 되살릴 수 있습니다.
  • 표 위 반출량 표시 체크 — 덤프트럭 반출량 열을 켜고 끕니다.

6. 기록 고치기 (목록의 줄을 누르기)

  • 맨 위에 기록 시각(입차 · 출차 · 머문 시간)이 보입니다.
  • 입차·출차 사진이 창 안에 나옵니다 — 두 손가락 확대, 한 손가락 이동, 두 번 누르면 그 자리 3배 / 다시 두 번 = 원래대로. 번호판을 보며 입력칸을 고칩니다.
  • 입차만 또는 출차만 있는 기록은 입차 / 출차를 골라 바꿀 수 있습니다(잘못된 모드로 찍었을 때).
  • 수정(임시 기록은 확인 완료) · 삭제.
출차로 묶기 — 고친 기록이 «입차만» 이고, 그 뒤에 같은 번호의 «입차만» 기록이 또 있으면 「같은 차의 출차일까요?」 창이 두 기록의 시각과 함께 뜹니다. 출차로 묶기 를 누르면 뒤 기록이 앞 기록의 출차로 합쳐집니다(시간 제한 없음). 번호를 못 읽어 입차로 두 번 찍힌 같은 차를 정리할 때 씁니다.

7. 임시저장 검증 (한가할 때)

  1. 하루 기록 → ⏳ 임시저장만 보기.
  2. 줄을 눌러 사진을 확대해 보고 번호를 고칩니다(«미인식»이면 칸이 비어 있습니다).
  3. 모드가 틀렸으면 입차/출차를 바꿉니다.
  4. 확인 완료 → 임시 표시가 없어지고, 그 번호가 인식 실패 자료의 정답으로 자동 기록됩니다(다음 검증자료 보내기에 다시 포함).
  5. 묶을 출차가 있으면 «출차로 묶기» 창이 뜹니다.

8. 공유·내보내기

버튼내용
전체 복사그날 기록을 전달용 글(PLATELOG 형식)로 복사.
공유 → 데이터 공유같은 글을 메신저 등으로 보냅니다.
공유 → HTML로 공유보기 좋은 표 문서.
공유 → 엑셀로 공유A4 인쇄용 배치의 엑셀. 설정에서 «엑셀에 검증 데이터 첨부»를 켜면 잘라 낸 번호판 그림이 든 «검증 데이터» 탭이 추가됩니다.

요약 숫자 읽는 법(v1.38): 예) 방문 차량 15대 · 입차 14건 · 출차 15건 (출차만 기록 1건 포함) · 주차 중 0건.
입차·출차는 각각 실제 찍힌 기록 수이고, 짝이 안 맞는 것은 괄호로 따로 알려 줍니다. 차량별 상태에는 «출차(입차 기록 없음)»으로 나옵니다.

9. 설정 (하루 기록 › 위 메뉴 «설정»)

묶음항목
① 현장·반출량현장 이름 · 반출량 계산·표시(덤프트럭 현장용, 끄면 주차 관리용) · 1회 적재량·단위
② 현장 차량 목록보관 일수(기본 7일 — 그동안 다시 안 온 차는 빠짐) · 목록 보기(누르면 빼기, 직접 넣기)
③ 원본 사진보관 일수(기본 30일, 0 = 오늘 것만) · 사진 장수·용량 · 지난 사진 지우기. 사진이 지워져도 기록은 남습니다.
④ 정확도 향상·검증정확도 향상 데이터 모으기(찍은 사진마다 검증자료 저장) · 엑셀에 검증 데이터 첨부

10. 검증자료관리 (하루 기록 › 위 메뉴)

앱의 인식률을 높이려고 모은 사진·번호판 그림·인식 결과입니다. 개발자에게 보낼 때 씁니다.

버튼뜻
새 자료 zip 으로 보내기아직 안 보낸 세트만 zip(17MB 조각)으로 만들어 텔레그램 등으로 보냅니다.
최근 보낸 자료 다시 보내기(v1.40) 보내는 도중 받을 곳을 못 고르고 끝났거나 전송이 실패했을 때, 바로 직전에 보낸 묶음을 똑같이 다시 만들어 보냅니다.
지우기…모두 지우기(되돌릴 수 없음) · 보낸 표시만 지우기(다음에 전부 다시 보냄).
텔레그램은 20MB 넘는 파일을 못 받아서 자동으로 조각을 나눕니다. 조각 여러 개는 한 번에 모두 골라 보내세요.

11. 잘 찍는 요령

  • 빨간 점을 번호판 안에 — 가장 효과가 큽니다.
  • 번호판이 화면 가로의 1/3 이상 되게 — 멀면 두 손가락으로 확대.
  • 가능하면 정면에서, 흔들리지 않게. 비스듬해도 앱이 펴서 읽지만 정면이 가장 정확합니다.
  • 흙이 심하게 묻은 판은 뒤 4자리만이라도 보이게 — 현장 차량 목록이 나머지를 맞춰 줍니다.
  • 바쁠 때는 임시저장 으로 넘기고 나중에 7장 순서로 정리.

12. 자주 묻는 것

Q. 「번호판 위치를 못 찾았습니다」가 뜹니다.
번호판이 작거나 점 밖에 있었던 경우입니다. 확대하고 빨간 점을 번호판 안에 두고 다시 찍으세요. 급하면 임시저장.
Q. 같은 차가 입차로 두 번 기록됐어요.
앞 기록을 눌러 번호를 확인하고 «수정» → 「같은 차의 출차일까요?」에서 «출차로 묶기». 또는 뒤 기록을 열어 «출차»로 바꾸세요.
Q. 기록을 실수로 지웠어요.
하루 기록 위 «↺ 삭제한 기록 복구».
Q. 인터넷이 없어도 되나요?
네. 인식·저장 모두 폰 안에서 합니다. 보내기·공유할 때만 그 앱(메신저)이 인터넷을 씁니다.
